# 🚀 Running Locally

Clone the repository

```bash
git clone https://github.com/Harshaapoorv/harshaapoorv-portfolio.git
```

Navigate into the project

```bash
cd harshaapoorv-portfolio
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Build production

```bash
npm run build
```
